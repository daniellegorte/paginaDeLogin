# Página de Login

## Objetivo

O projeto tem como objetivo desenvolver uma interface visual de uma página de login, utilizando HTML e CSS, com foco na construção de formulários, organização de elementos e estilização de páginas web.
A proposta é criar uma tela de autenticação com design moderno, intuitivo e agradável, aplicando conceitos de desenvolvimento Front-End.

- **CSS3:** estilização da interface, posicionamento dos elementos, cores, efeitos visuais e personalização do formulário.
- **Boxicons:** biblioteca de ícones utilizada para representar visualmente os campos de usuário e senha.
- **Google Fonts:** utilização da fonte Poppins para a identidade visual da interface.

## Funcionalidades

A interface apresenta os seguintes elementos:

- **Campo de usuário:** entrada para identificação do usuário, utilizando campo de e-mail.
- **Campo de senha:** entrada para senha com caracteres ocultos.
- **Lembrar senha:** opção de seleção por meio de checkbox.
- **Esqueci a senha:** link disponibilizado para recuperação de acesso.
- **Botão de Login:** botão para envio do formulário.
- **Cadastro:** link para direcionamento à área de criação de conta.
